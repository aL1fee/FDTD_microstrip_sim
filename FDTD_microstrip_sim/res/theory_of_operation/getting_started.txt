Start a 1D run

* Step Once - Advance exactly one solver update.

1. Choose 1D in the Simulation controls. Set the X length and cell size in millimeters before running.
2. Insert a Power source. Place its cylinder across the X axis, with its injection endpoint inside the grid.
3. Choose Execute > Run. Blue and red curves show the normalized electric and magnetic fields.
4. Use Execute > Stop to pause, Run to continue, or Reset to return to the initial field state.
5. Use Step Once to advance a single Yee update. The first Gaussian samples can be too small to see. The step counter confirms each advance.
