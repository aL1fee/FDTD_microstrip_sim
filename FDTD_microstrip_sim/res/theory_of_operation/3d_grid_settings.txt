3D grid settings

* Shared scene grid
Choose 3D in the main Simulation window to expose X, Y, and Z dimensions. Set the dimensions and Cell size in the units selected under Tools > Length units. In the 3D cavity window choose Grid > Configured domain, select a Material independently, review the proposed grid, and click Apply / Reset. Both the main fields and the Settings menu edit the same scene-grid values.

* Validation preset
Grid > Fixed cavity validation preset selects the fixed 24 x 20 x 16 grid with 500 um cells (12000 x 10000 x 8000 um). This explicit preset ignores scene-grid edits. Select Vacuum and Standing wave with this preset for the original frequency reference. Material choice alone never changes grid dimensions.

* Grid extent
For each axis, N = floor(requested length / cell size). Float input rounding near an integer ratio is tolerated. The active physical extent is N * cell size; a fractional remainder is omitted. The origin is (0,0,0). Cells are cubic and uniform; each axis needs 2 to 1000 cells. The window shows the active extent separately from proposed settings. A wireframe in the scene marks the applied solver boundary. The observation plane spans that boundary and its slider is limited to samples inside it. The main cell-grid preview can differ while edits are pending or the explicit preset is active.

* Applying changes
Changing grid or material settings pauses the 3D run. Apply / Reset rebuilds coefficients and conductor masks and resets fields, time, and frequency measurements. Geometry edits also require Apply / Reset. Rejected settings retain the previous fields, clearly labeled as the last applied domain. Before the first successful Apply there is no solver, plot, or observation plane; invalid settings do not silently fall back to a preset. The Z slider is limited to the active grid, including after shrinking it.

* Memory estimate
The estimate includes all six field arrays, three electric coefficient arrays, and packed conductor masks. Reset also needs temporary material arrays while the previous solver remains alive. An internal 512 MiB memory limit reserves space for replacing the new grid again. Estimates exclude the rest of the application and graphics-driver memory. Large allocations are rejected before solver construction; increase cell size or reduce the domain.

The original 4500 x 2000 x 7000 um scene with 20 um cells has 225 x 100 x 350 = 7875000 cells and exceeds this reset budget. With 50 um cells it has 90 x 40 x 140 = 504000 cells. These are allocation examples, not claims of sufficient accuracy for a particular trace.

* Physical timestep
The solver uses dt = 0.5 * dx / c0, with dx in meters. Changing cell size changes the physical time per step. Playback still targets 80 steps per screen second and can slow down on large grids. The standing-wave initial condition and center probe scale with grid dimensions.

* Unresolved geometry
A conductor dimension smaller than one cell produces a warning before applying. Zero mapped samples after applying means the conductor is absent from the discrete model. A nonzero count is not proof of geometric accuracy. Real thin copper still needs resolution studies or a validated thin-sheet model.

* Current simulation scope
The outer boundaries remain PEC, materials are lossless, and excitation can be a standing wave, a bidirectional X pulse initial field, or a normalized drive from Source objects. See 3D slices and X pulse. The main Simulation window legacy source-power, CW-frequency, and boundary controls do not drive this 3D solver. Scene sources uses each Source object's own frequency and normalized amplitude instead. This step connects grid settings; it does not implement ports, open boundaries, or copper losses.
